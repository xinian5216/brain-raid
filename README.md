# 尸潮夜袭 Brain Raid

像素风反向塔防：你是僵尸一方。从墓园派出部队，啃穿植物防线，冲进屋子吃掉脑子。

电脑横版（屋子在左），手机竖版（屋子在上）。点行道部署僵尸即可。

## 怎么玩

- 底部选择僵尸，点击花园里的一条行道放出。它们会自动走向屋子。
- 电脑：`1–5` 选兵，点击行道部署，`Esc` 暂停。
- 月光会随时间回复，啃掉植物也能抢一份。日轮花最肥。
- 摸到屋子就吃一颗脑子。吃够即胜；黎明到了还没吃够则败。

## 夜晚

1. **初夜** — 只有豆炮，吃 2 脑
2. **路障夜** — 坚盾挡路，解锁锥帽
3. **霜降** — 霜叶减速，解锁铁桶
4. **重甲冲锋** — 解锁冲锋尸
5. **脑园终夜** — 五颗脑子
6. **无尽夜袭** — 两分钟里能吃几颗算几颗

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开提示的地址即可。构建：

```bash
npm run build
npm run preview
```

## 技术

React 19、TanStack Start、Canvas 2D、Tailwind v4。进度存在浏览器 `localStorage`。
